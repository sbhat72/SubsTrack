# SubsTrack

A personal subscription manager that tells you exactly what you're paying,
when to cancel, and when your prices went up without you noticing.

## Features
- **Cancellation Timing Engine** — exact last safe day to cancel before next charge
- **Price Creep Tracker** — automatic detection when a service raises its price
- **12-Month Forecast** — full spending projection across all subscriptions
- **Bank Connection** — Plaid integration to detect subscriptions automatically

## Stack
Java 21 + Spring Boot 3 · Next.js 15 + TypeScript · PostgreSQL · Plaid
